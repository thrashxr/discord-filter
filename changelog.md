# Changelog

## Major

The package architecture has been completely redesigned to be more powerful and flexible. 🚀

-  Switched to a new usage pattern that offers better control over the filtering system.

## Minor

-  Added a smart filter feature that catches words hidden by repeated characters or symbols.
-  Included built-in blocklists for English and Turkish profanity and ads (enabled by default).
-  Improved performance to ensure faster message checks.

## Patch

-  Added autocomplete support (TypeScript definitions) to make coding easier.
-  Fixed an issue where innocent words like "book" were sometimes incorrectly flagged.
